   is silently dead in B42 -- neither of the two paths the loader checks
   reaches it, and nothing is logged when it is missing.

   One dot in the option id nests it: OffGrid.LinkRadius becomes
   SandboxVars.OffGrid.LinkRadius. Two dots would not nest and the option
   would land flat at the top level instead. */

/* Who may pick a placed part back up. 1 anyone, 2 anyone with a screwdriver,
   3 the person who placed it plus their safehouse plus admins.

   This exists because the mod cannot rely on the base rule: any mod that
   loosens canPickUpMoveable (Rebalanced Prop Moving is the obvious one)
   otherwise makes every panel free to take. Enum values are 1-based, and
   an enum option requires numValues > 0 AND default > 0 or it is rejected. */

option OffGrid.PickupLock
{
    type = enum,
    numValues = 3,
    default = 3,
    page = OffGrid,
    translation = OffGrid_PickupLock,
    valueTranslation = OffGrid_PickupLock,
}

/* Building wiring and transformers (2026-09-24).

   GridLinkRadius is how far one transformer's power line may run, to the
   controller or to another transformer. It is longer than LinkRadius, which is
   for panels and batteries, so that transformers can be spaced to keep a
   street lit end to end: each lights its own GeneratorTileRange circle.

   TransformerLoss is what each powered transformer draws doing nothing, in
   watts, so a sprawling grid costs something to keep running. */

option OffGrid.GridLinkRadius
{
    type = integer,
    min = 8,
    max = 60,
    default = 30,
    page = OffGrid,
    translation = OffGrid_GridLinkRadius,
}

option OffGrid.TransformerLoss
{
    type = integer,
    min = 0,
    max = 500,
    default = 25,
    page = OffGrid,
    translation = OffGrid_TransformerLoss,
}

/* Realistic Mode: panels produce what 1993 panels did (Alwar's figures on the
